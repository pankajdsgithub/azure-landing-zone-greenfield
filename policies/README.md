# Governance and Azure Policy

This directory documents the planned governance framework.

## Areas to Define

- Allowed Azure regions and resource types.
- Required tags and naming conventions.
- Security baselines and diagnostic settings.
- Public network exposure restrictions where appropriate.
- Encryption and identity requirements.
- Exceptions, ownership and expiry/review procedures.

Policy definitions and assignments will be implemented only after requirements,
scope and exemptions are reviewed. Avoid blanket assignments that could disrupt
existing workloads.
